Installer OB Max

Le guide pour regarder les films et séries du serveur OB Max sur ton téléphone, ta TV ou ton ordinateur.

📱 Téléphone 📺 TV 💻 Mac / PC 🌐 Web

🔑Avant de commencer

OB Max est un service privé. Chaque appareil s'active avec un code personnel que t'envoie l'administrateur.

  • Ton identifiant et ton mot de passe : les mêmes que dans Moonfin ou Jellyfin. Si tu n'en as pas encore, l'administrateur te les donne.
  • Un code d'invitation par appareil (téléphone, TV…) : 12 caractères, sous la forme ci-dessous. Il fonctionne une seule fois et pendant 48 heures.
  • Pour le navigateur web uniquement : un fichier certificat (.p12) et son mot de passe, envoyés par l'administrateur.
7K3Q–M9TA–2XWE
Garde ton code et ton certificat pour toi. Ils sont liés à ton compte et à ton appareil. Pour un nouvel appareil, demande simplement un nouveau code à l'administrateur.
iPhone, iPad, Apple TV ? Il n'y a pas d'appli OB Max pour ces appareils. Demande à l'administrateur ce qui est possible pour toi. Les Mac ont, eux, leur appli : voir la partie Mac / PC.

📱Smartphone Android

Environ 5 minutes. Fais-le directement sur le téléphone.

  1. Télécharger l'appli

    Sur ton téléphone, ouvre ce lien :

    github.com/ollivv-hash/obmax-releases/releases/latest

    Descends jusqu'à la rubrique Assets, puis touche le fichier obmax-mobile-…apk (le numéro de version change, prends celui qui commence par obmax-mobile).

    Si Chrome prévient que le fichier peut être dangereux, touche Télécharger quand même.

  2. Installer

    Ouvre le fichier téléchargé (notification de téléchargement, ou appli Fichiers > Téléchargements).

    • La première fois, Android bloque l'installation : touche Paramètres, active Autoriser cette source, puis reviens en arrière.
    • Touche Installer.
    • Si Play Protect affiche « Appli inconnue », touche Plus de détails puis Installer quand même. C'est normal : l'appli ne vient pas du Play Store.
  3. Activer avec ton code

    Ouvre OB Max. L'écran Activer OB Max s'affiche : tape ton code d'invitation et valide.

    Les tirets, les majuscules et minuscules n'ont pas d'importance.

  4. Te connecter

    Ton identifiant est déjà rempli. Tape ton mot de passe et connecte-toi.

C'est prêt ! Si tu avais Moonfin, tu peux maintenant le désinstaller : son ancienne adresse va bientôt cesser de fonctionner.
En 4G : pour économiser ton forfait et éviter les coupures, baisse le débit dans Réglages > Lecture > Débit maximal en streaming (par exemple 5 ou 10 Mbit/s).

📺TV Android, Google TV, Nvidia Shield

Environ 10 minutes, avec la télécommande. Garde ton téléphone à portée de main pour l'étape 4.

  1. Installer l'appli « Downloader »

    Sur la TV, ouvre le Play Store, cherche Downloader (icône orange, éditeur AFTVnews) et installe-la. Elle sert à télécharger OB Max.

  2. Autoriser Downloader à installer des applis

    Dans les paramètres de la TV, va dans :

    • Android TV / Shield : Paramètres > Préférences de l'appareil > Sécurité et restrictions > Sources inconnues
    • Google TV : Paramètres > Système > Confidentialité > Sécurité et restrictions > Sources inconnues (ou Applications > Sécurité et restrictions selon le modèle)

    Active Downloader dans la liste.

  3. Télécharger et installer OB Max

    Ouvre Downloader. Dans le champ d'adresse, tape :

    github.com/ollivv-hash/obmax-releases/releases/latest

    puis Go. La page s'ouvre dans Downloader : descends jusqu'à Assets et clique sur obmax-tv-…apk (celui qui commence par obmax-tv).

    Une fois le téléchargement fini, choisis Installer. Downloader propose ensuite de supprimer le fichier : accepte (Supprimer), il ne sert plus.

  4. Activer avec ton code

    Ouvre OB Max. L'écran Activer OB Max propose deux façons de saisir le code :

    • Le plus simple : avec ton téléphone connecté au même Wi-Fi que la TV, scanne le QR code affiché (appareil photo du téléphone). Une page s'ouvre : tape le code puis Envoyer à la TV. Le message « Code envoyé. Regardez la TV. » confirme l'envoi.
    • Ou tape le code directement avec la télécommande.
  5. Te connecter

    Ton identifiant est déjà rempli. Tape ton mot de passe avec la télécommande.

C'est prêt ! Tu peux désinstaller Moonfin de la TV si tu l'avais.
Le QR code ne marche pas ?

Vérifie que le téléphone est bien sur le même réseau Wi-Fi que la TV (pas en 4G, pas sur un Wi-Fi « invités »). Sinon, tape simplement le code à la télécommande : le résultat est le même.

💻Ordinateur : Mac et PC Windows

Environ 5 minutes. Comme sur téléphone, l'appli s'active avec un code d'invitation.

Mac (macOS 15 Sequoia ou plus récent)

  1. Télécharger

    Ouvre ce lien sur le Mac :

    github.com/ollivv-hash/obmax-releases/releases/latest

    Dans Assets, clique sur obmax-macos-…dmg.

  2. Installer

    Ouvre le fichier téléchargé, puis glisse l'icône OB Max sur le dossier Applications. Tu peux ensuite éjecter le disque « OB Max ».

  3. Premier lancement

    Ouvre OB Max depuis Applications. La première fois, macOS refuse de l'ouvrir car l'appli ne vient pas de l'App Store : clique sur Terminé.

    Va dans Réglages Système > Confidentialité et sécurité, descends jusqu'au message sur OB Max et clique sur Ouvrir quand même, puis confirme avec ton mot de passe ou Touch ID. Ce n'est à faire qu'une fois.

  4. Activer et te connecter

    Tape ton code d'invitation, puis ton mot de passe (l'identifiant est déjà rempli).

PC Windows 10 ou 11

  1. Télécharger

    Ouvre le même lien sur le PC et clique sur obmax-windows-…exe dans Assets. Si le navigateur trouve ce fichier « peu téléchargé », choisis Conserver.

  2. Installer

    Lance le fichier. Windows affiche « Windows a protégé votre ordinateur » : clique sur Informations complémentaires, puis Exécuter quand même. Accepte la demande d'autorisation, puis suis l'assistant (Suivant, Installer).

  3. Activer et te connecter

    Ouvre OB Max (menu Démarrer), tape ton code d'invitation, puis ton mot de passe.

C'est prêt ! Les avertissements de macOS et de Windows viennent du fait que l'appli n'est pas vendue dans leurs boutiques. Ils n'apparaissent qu'à l'installation.

🌐Navigateur web (sans appli)

Pour un ordinateur où tu ne peux pas installer l'appli (par exemple au travail). Ici, pas de code d'invitation : l'administrateur t'envoie un fichier certificat (prénom.p12) et son mot de passe. Tu l'installes une fois sur l'ordinateur.

1. Installer le certificat

Windows (Chrome, Edge)
  1. Double-clique sur le fichier .p12

    L'assistant Importation du certificat s'ouvre. Choisis Utilisateur actuel, puis Suivant deux fois.

  2. Mot de passe

    Tape le mot de passe envoyé par l'administrateur, puis Suivant.

  3. Terminer

    Laisse Sélectionner automatiquement le magasin, puis Suivant et Terminer.

  4. Redémarre le navigateur

    Ferme toutes les fenêtres de Chrome ou Edge, puis rouvre-le.

Mac (Safari, Chrome)
  1. Double-clique sur le fichier .p12

    L'appli Trousseaux d'accès s'ouvre. Choisis le trousseau session.

  2. Mot de passe

    Tape le mot de passe envoyé par l'administrateur.

  3. Redémarre le navigateur

    À la première connexion, le Mac peut demander l'accès à la clé du certificat : tape le mot de passe de ta session Mac et choisis Toujours autoriser.

Firefox (Windows ou Mac)

Firefox a sa propre liste de certificats : Paramètres > Vie privée et sécurité > Certificats > Afficher les certificats > Vos certificats > Importer…, choisis le fichier .p12 et tape son mot de passe.

2. Ouvrir OB Max

  1. Va sur l'adresse du serveur

    Celle que t'a donnée l'administrateur avec ton certificat (elle commence par https://).

  2. Choisis le certificat

    Le navigateur te demande quel certificat utiliser : choisis OB Max – ton prénom, puis OK.

  3. Connecte-toi

    Avec ton identifiant et ton mot de passe habituels.

Astuce : ajoute la page à tes favoris. Le navigateur se souviendra du certificat.
« Ce site ne peut pas fournir de connexion sécurisée » ou ERR_BAD_SSL_CLIENT_AUTH_CERT ?

Le navigateur n'a pas présenté le certificat. Vérifie qu'il est bien installé, puis ferme complètement le navigateur et rouvre-le. Si tu as choisi le mauvais certificat, ouvre une fenêtre de navigation privée : le navigateur te reposera la question.

🔄Mises à jour

OB Max se met à jour depuis l'appli, sans rien perdre.

  • Quand une nouvelle version sort, OB Max affiche OB Max x.y.z est disponible : choisis Mettre à jour puis confirme l'installation.
  • La première fois, Android demande d'autoriser OB Max à installer des applis : touche Ouvrir les réglages, active Autoriser depuis cette source, puis reviens dans OB Max.
  • Sur Mac, l'appli propose de télécharger la nouvelle version : ouvre-la et glisse OB Max dans Applications en remplaçant l'ancienne. Sur Windows, elle télécharge et lance le nouvel installateur.
  • Pour vérifier toi-même : Réglages > À propos > Rechercher une mise à jour.
  • Ton activation se renouvelle toute seule quand tu ouvres l'appli. Si tu ne l'as pas ouverte depuis environ 6 mois, elle te redemandera un code : demande-en simplement un nouveau à l'administrateur.

🛟En cas de souci

« Ce code n'est pas valide ou a expiré. »Vérifie la saisie (le chiffre 0 et la lettre O sont équivalents, de même que 1, I et L). Un code ne marche qu'une fois et pendant 48 h : demande-en un nouveau à l'administrateur.
« Trop d'essais. Réessayez dans une heure. »Trop de codes faux d'affilée. Attends une heure, puis réessaie avec le bon code.
« Service d'activation injoignable »L'appareil n'a pas accès à internet. Vérifie le Wi-Fi ou la 4G, puis réessaie.
« Cet appareil a été révoqué. »L'accès de cet appareil a été coupé. Contacte l'administrateur.
« OB Max ne peut pas être ouvert » (Mac) ou « Windows a protégé votre ordinateur »Normal au premier lancement : voir la partie Mac / PC (« Ouvrir quand même », « Exécuter quand même »).
Nouveau téléphone, TV réinitialisée, appli réinstalléeIl faut un nouveau code : demande-le à l'administrateur, puis suis à nouveau le guide.
